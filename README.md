# ZoomMeetingBook — public downloads

This repository contains **release APKs only**. Application source code is maintained in a private repository.

Install the latest build from [Releases](https://github.com/jphutching/ZoomMeetingBook-Releases/releases/latest).

Releases are mirrored automatically from the private source repository when you run `./scripts/release.sh`.

## Verify before installing

- Download only from this official releases page.
- Android may warn about installing apps outside Google Play; that is expected for direct APK installs.
- Prefer [Google Play](https://play.google.com/store/apps/details?id=com.jphutching.zoommeetingbook) when available.
